# BIT235 Workshop 6 - Java Collections & OOP Concepts

Java programs for BIT235 Object Oriented Programming, Workshop 6.

| File | Exercise | Topic |
|------|----------|-------|
| Exercise1.java | 1 (Easy) | 10 favourite songs and artists stored in two parallel arrays |
| Exercise2.java | 2 (Hard) | Exercise 1 sorted alphabetically with a bubble sort (artists stay with their songs) |
| Exercise3.java | 3 (Medium) | Reverse the letters of every word in a sentence |
| Exercise4.java | 4 (Easy) | Decode a message with a substitution key |
| Exercise5.java | 5 (Medium) | Simple search engine over an array of 10 paragraphs |
| IdentifyMyParts.java | 6 (Easy) | Class variables (static) vs instance variables |
| Boxes.java / BoxDriver.java | 7 (Medium) | A class that draws square boxes plus a driver class |

## How to compile and run

```bash
javac Exercise1.java
java Exercise1
```

```bash
javac IdentifyMyParts.java
java IdentifyMyParts
```

```bash
javac Boxes.java BoxDriver.java
java BoxDriver
```
